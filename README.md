# zenday-social

Public on purpose: the images and videos of Zenday's Instagram and TikTok posts, so the scheduler
(Metricool) can fetch them by URL and publish automatically.

Only material that is published anyway goes here — nothing else. The working files, sources and
everything about the platform stay in the private repository.

Layout: `YYYY-MM/<post>/<format>/NN.jpg` — `4x5` for the Instagram feed, `9x16` for TikTok and stories.
